1. **Missed links / The word gate (Checks 3 & 4)**: There is a critical logic flaw in `isLinkable(topic, codeSpan)` for one-word topics. The function checks `codeSpan.trim().toLowerCase() === topic`. However, `topic` is the CANONICAL topic name passed from `resolveRun` (which preserves its original case from the `topics` array). If a one-word topic contains any uppercase letters in its canonical name (e.g., `Roadmap` or `Releases`), this strict equality check against a lowercased `codeSpan` will always evaluate to `false`. As a result, such topics will never be linked, even when correctly wrapped in backticks. The check must use `topic.toLowerCase()`.
