### 2. False links — **holds**
`RUN_RE` is `/[A-Za-z0-9._~\-/\\@:?#=&%+]+/gu`. After the earlier `?`/`=` miss, the class still omits RFC 3986 sub-delimiters `,` and `;`. The run therefore splits a URL and offers the slug after the break:

- `See https://example.com/a;commonswarm-roadmap` → runs `https://example.com/a`, `commonswarm-roadmap`
- `https://example.com/x?ids=1,2,shared-host` → runs `https://example.com/x?ids=1`, `2`, `shared-host`

`commonswarm-roadmap` / `shared-host` are live slug-shaped topics, so they become buttons **inside a URL**. That is exactly the class Check 2 asked for (and the class Gemini already hit on `?`/`=`). Existing tests do not catch it: they use `/`, `?`, `=`, `&`, `#` — all already in the class. `PRE` / `<a>` / prefix-`roadmap` / sentence-final `.` / unknown names are fine; this hole is not.
