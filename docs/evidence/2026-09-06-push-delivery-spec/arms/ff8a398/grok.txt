## DEFECT

**D1. §4.1** — Claim: watcher calls `claim_agent_inbox` with `limit: 0`; `durable-delivery.ts:273` leases nothing.

The inner guard is real. The edge never sees `0`.

- `command/index.ts:1510` uses `integer(limit, 1)` (`:1435-1436`, `>= 1`). `limit: 0` is 400.
- Missing `limit` defaults to 10, not 0 (`:1500-1502`).
- `DeliveryCommandClient.claimAgentInbox` hard-codes `limit: 1` (`delivery.ts:827-830`). The request type has no `limit` field.

L5 does not own those files. As written, the watcher cannot learn `wake.topic` without taking a lease.

**D2. §2.3 / §3.1** — Claim: skip the per-tick read while subscribed; `record_renewal_grant_use` (`read/index.ts:490-496`) drops; the claim replaces it.

Claims do not stamp grant use. The claim branch returns at `command/index.ts:8433-8452`. `record_renewal_grant_use` at `:9024-9036` is on the protocol path; renewals are excluded at `:9027`. Standing grants suspend after 14 days without that stamp (`20260901000001_standing_grants.sql:199-207`). Today the inbox read is what keeps a live idle seat “used”. After L4, a push-mode idle listener with a standing grant pauses its own renewal. §2.5 says credential rotation stays as it is.

**D3. §1.3 / §3.1 / §3.2** — Claim: empty claim upserts `rate_buckets` at `:4850`, one row per principal per hour, 24 rows/day.

`:4850` is `incrementRateBucket` (signals, hour window). Claims use `checkDeliveryRateLimit` (`:4868`, `:7533`) with `date_trunc('minute')` at `:4881-4888`. CodexDesktop’s server pass already named `:4868`. Per idle seat-day that is 1,440 minute-window rows (2-hour purge), not 24 hourly rows.

**D4. §6 L2** — Claim: tests live at `tests/p1-local/wake-realtime-auth.test.ts`.

`test:p1-local` is a literal eight-file list (`package.json:26`). `tests/p1-cli/test-gate-coverage.test.ts:23-34,125-128` pins that string. A new file in that directory either never runs or turns `npm test` red. L2 does not own `package.json` or the coverage test.

**D5. §6 L2 / “0.1.56 keeps working because additive schema”** — Claim: adding `agent_tokens.wake_key` is additive.

Mint/renew INSERT lists columns and omits `wake_key` (`command/index.ts:3678-3694`, `:4376-4392`). L2 does not own those sites. The spec never says NULL or DEFAULT. `NOT NULL` with no default fails every mint/renew. A 0.1.56 seat would die at L2 apply.

**D6. §6** — L1 owns `command/index.ts:8348-8445` only. L3 owns claim response builders. The claim body is `:8433-8452`, inside L1’s range. Order has L1 independent and L3 after L2, so both can edit the same lines.
