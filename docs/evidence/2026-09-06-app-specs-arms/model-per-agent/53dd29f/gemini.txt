### Inversion Analysis of Load-Bearing Choices

1. **Choice 1: Retain `model` as declaration and add `assigned_model`, rather than keeping `model` as assignment and adding `declared_model`.**
   - *Inversion:* Keep `model` as human assignment (matching `set_agent_model` / `create_agent_principal` semantics) and add `declared_model` for the agent's start declaration.
   - *Predicted Regression:* Breaks rolling upgrades. Unupgraded listeners in the field fire `declare_agent_model { model }` on startup. If `model` held human intent, legacy listeners would clobber operator assignments on restart.

2. **Choice 2: Synchronous pre-bridge inbox read (`readAgentSignalPage`) exiting fatally on failure before bridge construction.**

   - *Predicted Regression:* ACP bridges (Claude/Codex) and Grok instantiate models immutably at constructor time before entering `runListenerRuntime`. Deferring read or falling back to default risks executing instructions under the wrong model, incurring unintended billing and misaligned behavior.
   - *Verdict against spec:* Did not beat spec. Fail-fast is correct because a seat unable to read its inbox cannot serve.

3. **Choice 3: Explicit persisted `model_assignment_state` column (`honoured | no_mapping | cli_override | pending`) instead of dynamic string comparison.**
