`package.json:26` is `test:p1-local` (literal list). The pin is `tests/p1-cli/test-gate-coverage.test.ts:23-35` and `:125-129`. Spec says “named in `package.json:26` + pin” and does not name the pin file or the new test path.

**§4 L2 — `tests/listener-*.test.ts` is not a gate glob.**  
`npm test` (`package.json:23`) is a literal list. A new `tests/listener-….test.ts` does not run until that list names it. Spec does not say to edit `package.json:23`.

**§2.3 L3 — `normalizedModel` is not on the site.**  
The mark rule names `normalizedModel` (`workspace-commands.ts:499-514`). That function is not exported. The site package cannot import `src/protocol`. No site helper is named.

**§2.1 — `create_agent_principal` both-keys rule is missing.**  
Edge code (`command/index.ts:2214-2216`) refuses a body that has both `model` and another optional key. “Old key accepted for one release” does not say what happens when both keys are present, which key wins, or which release ends it.

**§2.1 / §3 — overwritten rows.**  
Backfill uses one newest event. The §1 case (person set, then listener declare) has newest = agent declare → `assigned_model` stays NULL. §3 bullet 1 can be read as “a row a person set keeps its value in `assigned_model`.” The spec does not say whether to recover the older person event.

**§2.3 — omitted `assignment_state`.**  
The field is optional. The handler’s action when an old listener omits it is not named (leave `pending`? leave unchanged?).
