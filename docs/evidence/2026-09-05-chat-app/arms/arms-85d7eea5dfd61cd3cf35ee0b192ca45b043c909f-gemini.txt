   *What breaks:* The failure path updates the `signals` array to remove the `pending` rows (and prepend any partially successful rows via `visibleOnFailure`), but it NEVER calls `renderFeed()`. 
   *How you would see it:* If a post fails (or partially fails) while you stay in the channel, the status bar shows an error and the text is returned to the composer box.
