### 4. The clamp

CTE computes `until_value` once. WHERE tests that same value on both branches (`command/index.ts:6888-6933`).

- Stored row cannot outlive the root: WHERE is `until_value <= untilCeiling`. If `GREATEST(..., now+1ms)` raises past the ceiling, the INSERT returns zero rows.
- Legal defaulted reply: `LEAST(default, ceiling)` then `GREATEST(..., 1ms)`. Note/ask defaults are 30d/7d. While remaining > 1ms, the row stores. The 1s floor in `resolveThreadRoot` (`:1450`) leaves a stall margin.
- CHECKs (`20260724000003:14-15`): floor is `created_at + 1ms`, so `until > created_at` cannot fire on this INSERT. `until_ms` is capped at 30 days (`SIGNAL_MAX_UNTIL_MS`). `GREATEST` does not add 1ms on top of a 30-day value. A clamped reply uses `root.until`, which is already inside the root’s 30-day window, so it is inside the reply’s window too.

A legal explicit horizon that fitted at SELECT can still 409 at INSERT if time passed. That is the atomic arm, not a silent shorten.

### 11. The two strengthened tests

**First-rule test** (`chat-signals.test.ts:643-678`): `not-a-uuid`+channel, nil uuid+channel, `purpose: 123`, `purpose: "x"*501`. Each names a different sentence. If the uuid check moved below “takes no channel”, `assert.match(..., /thread_root_id is the id/)` fails. If purpose type/length were one sentence, the `123` equality fails. These can fail.

**`until === root.until`** (`:4689-4694`): root `until_ms: 90_000`, reply is a defaulted **note** (30d). `LEAST(now+30d, root.until)` is `root.until`. `GREATEST(..., now+1ms)` still picks the ceiling while ~90s remain. For this setup, equality is right, not `<=`. A legitimate defaulted **ask** against a long-lived root would store `now+7d`, not `root.until` — but this test does not use that pair, so it is not flaky. ISO/ms round-trip: both sides go through `toISOString()` / `Date.parse`, so they compare at millisecond precision.
