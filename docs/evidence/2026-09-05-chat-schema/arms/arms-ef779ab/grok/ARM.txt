## 22. The clamp, third attempt

**Finding. An explicit `until_ms` that still fits the root can 409, and the message says the thread ended.**

`statement_timestamp()` is stable inside one statement. CTE and WHERE agree. A stored row cannot outlive its root: `until_value > ceiling` is refused. Handler mapping is correct now that the ceiling, not explicitness, is the condition: defaulted GREATEST-past-ceiling also 409s.

The early check is `command.until_ms > rootRemainingMs` (`:7763`), using `remaining_ms` from the previous `SELECT` (`:6434-6435`). The INSERT `WHERE` is `candidate.until_value <= untilCeiling` (`:6907-6909`), using `statement_timestamp()` of the INSERT. Those are different statements.

Take a root whose `until` is `T+90000ms`. `SELECT` at `T`. `remaining_ms` is `90000`. Caller sends `until_ms: 90000`. `90000 > 90000` is false, so no early 409. `INSERT` at `T'` > `T`. `until_value = T'+90000ms`. `WHERE`: `T'+90000ms <= T+90000ms` is false. Zero rows. 409:

```7827:7828:supabase/functions/command/index.ts
            message:
              `A reply cannot outlive the message its thread starts from, and that thread ended while this reply was being written. Post it again for a fresh horizon.`,
```

The thread has ~90s left. It did not end. The band is `until_ms ∈ (remaining_at_insert, remaining_at_select]`. Width is one SQL round-trip in the same transaction (milliseconds). Design (`docs/design/2026-09-04-chat-platform-reconciled.md:642-643`) says refuse only when the explicit horizon is longer than the remaining window. At write time it is longer by the gap; the sentence still claims the thread ended.

A client that copies the root's own `until_ms` is usually caught by the early check (remaining has already shrunk), with the honest `That thread ends at {iso}` sentence. The lying sentence is the atomic arm.

`GREATEST` vs `WHERE`: for explicit, stored `until` is `now+untilMs` (`until_ms >= 1`). An explicit row that inserts cannot outlive its root. For a default, a stall that eats the 1s floor 409s instead of storing past the root. That part holds.
