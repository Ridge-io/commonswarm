## 4. The clamp

No finding that a stored row can outlive its root, or that either CHECK on `swarm.signals` fires on this path.

The CTE computes the stored value once; the WHERE tests that value (`command/index.ts:6864-6931`). Explicit path stores `now + until_ms`. Defaulted path is `LEAST(now + default, ceiling)`. `GREATEST(..., now + 1ms)` is the floor against `CHECK (until > created_at)` (`20260724000003:14`). `until_ms` is already `integer(..., 1)` (`command/index.ts:1806-1809`), so the floor cannot raise an accepted explicit horizon.

`CHECK (until <= created_at + 30 days)`: reply `until` is `<=` root `until`, and root already satisfies the 30-day bound, and `statement_timestamp()` has moved forward, so the reply is strictly inside.

A defaulted reply whose 1s SELECT margin is eaten by stall is refused (zero rows → 409), not stored past the root. That is the designed refusal, not a silent shorten.
