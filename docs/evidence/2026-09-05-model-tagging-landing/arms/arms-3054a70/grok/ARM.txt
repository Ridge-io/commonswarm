### 2. The emitter can sign the wrong model as `runtime-transcript`

Probe order is a fixed list: codex, grok, agy, then `claude-code` last (`scripts/lib/agent-trailer-vocab.sh:97-102`; `scripts/agent-trailers.sh:225-231`). First match wins and returns.

`detect_codex` returns 0 as soon as `CODEX_THREAD_ID` is set (`scripts/agent-trailers.sh:120-154`). A Grok or `agy` child of Codex inherits that id, never reaches `detect_grok` / `detect_agy`, reads the parent's rollout, and writes the parent's model with `Agent-Model-Source: runtime-transcript`.

`docs/development/agent-trailers.md:114-129` calls the unlisted-runtime + inherited `CLAUDE_*` case "the one way this can produce a confident wrong value." That is false. The Codex-parent case is the same class, it is in the listed set, and nothing in the trailer says the session was the wrong one.

This session is the Claude-parent case: `CLAUDECODE=1` and `GROK_SESSION_ID` are both set; `--detect` returned `grok-4.6` / `runtime-config`. Claude-last works here. The hole is every listed parent that is not last.

### 3. The honesty field is not required

`AGENT_TRAILER_REQUIRED_KEYS` is only `Agent-Model` and `Agent-Family` (`scripts/lib/agent-trailer-vocab.sh:22-25`). The checker accepts a commit with those two and no `Agent-Model-Source` (`scripts/check-agent-trailers.sh:64-86`).

The lane claim lists four trailers. `.github/workflows/agent-trailers.yml:11-13` says the field is never silently absent, and that `Agent-Model-Source` tells a later reader whether the value was measured. A `--no-verify` commit can carry a typed model, omit the source, and go green. The audit then cannot tell measurement from assertion.

The hook always prints `Agent-Model-Source` (`scripts/agent-trailers.sh:271-275`). The gate does not. Absence of the hook is what the gate exists to catch; a partial hand-written block bypasses that for the one field the design says to read first.

### 4. The date cutoff cannot see the checkout that wrote the commit

Grace is author-date `< 2026-09-05T00:00:00Z` (`scripts/lib/agent-trailer-vocab.sh:161-162`; `scripts/check-agent-trailers.sh:51-54`). A lane that started before this SHA, on a tree with no hook, and that commits after the cutoff is required to carry trailers it could not emit. The cutoff answers "is the clock past this instant?", not "did this tree contain the hook?".

The inverse is disclosed: a new commit with an old `%at` is skipped (`scripts/lib/agent-trailer-vocab.sh:155-157`; `docs/development/agent-trailers.md:256-259`).

ISO and epoch agree (1788566400). The TypeScript test checks that (`tests/p1-cli/agent-trailers.test.ts:153-166`). The workflow self-test does not. It only fails a cutoff in the future (`scripts/check-agent-trailers.sh:465-482`).

Skipped commits are counted apart from checked ones on the OK line (`scripts/check-agent-trailers.sh:150-155`). Merge commits return 0 and are folded into `checked` (`scripts/check-agent-trailers.sh:56-61, 106-113`). A merge-only range reports work as checked that was only exempted.

Author date, not committer date, is the right rebase choice. A rebase that kept author dates would not revoke grace.

### 5. Some ranges check one commit, or none, and still exit 0

`.github/workflows/agent-trailers.yml:104-122`: when `before` is missing or unreachable and `origin/main` cannot be fetched, the range is `HEAD~1..HEAD`. A new-branch push of N commits then checks the tip only. The log says that one commit was checked.
