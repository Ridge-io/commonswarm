## 5. Installer Checksum-First Verification

**Claim:** *The checksum-first path fails closed on a malformed checksum and replaces damaged or changed bytes. A wrong reuse would ship a stale binary.*

**Refutation Analysis & Trace:**
1. Checksum Fetch & Validation ([`install.sh:84-92`](file:///Users/yulanbot/Developer/Ridge.io/cloud-swarm/install.sh#L84-L92)):
   - Fetches `$BASE/cswarm.sha256` first.
   - Extracts `EXPECTED="$(cut -d' ' -f1 < "$TMP/cswarm.sha256")"`.
   - Fails closed immediately if empty or non-hex (`case "$EXPECTED" in *[!0-9a-f]*|'') die ...`), or if string length is not 64 characters (`[ "${#EXPECTED}" = 64 ] || die ...`).
2. Byte Comparison & Safe Replacement ([`install.sh:104-122`](file:///Users/yulanbot/Developer/Ridge.io/cloud-swarm/install.sh#L104-L122)):
   - Checks SHA-256 of `$INSTALL_DIR/cswarm`. If matching `EXPECTED`, reuses local binary.
   - If missing, damaged, or changed, downloads `$BASE/cswarm`.
   - Computes `ACTUAL="$(cswarm_file_hash "$TMP/cswarm")"` and asserts `[ "$EXPECTED" = "$ACTUAL" ] || die ...`.
3. Pinned in Unit Test ([`tests/p1-cli/onboarding-installer.test.ts:10-53`](file:///Users/yulanbot/Developer/Ridge.io/cloud-swarm/tests/p1-cli/onboarding-installer.test.ts#L10-L53)):
   - Verifies repeat install reuses binary (manifest fetched, binary download skipped).
   - Verifies changed bytes in local installation trigger re-download and replacement.
   - Verifies malformed checksum (`"bad"`) exits code 1, refuses to install, and preserves the local binary.

**Refutation result:** REFUTED. Checksum-first fails closed and replaces altered binaries without stale reuse.
