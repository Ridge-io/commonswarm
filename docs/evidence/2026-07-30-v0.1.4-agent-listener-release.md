## What shipped

v0.1.4 is the first CommonSwarm release that can receive a direct ask after the
setup turn ends and deliver it to a model without cmux or terminal keystroke
injection:

```sh
cswarm listen start --agent-token-stdin \
  --workspace-id <uuid> --cwd <absolute-directory>
cswarm listen status --workspace-id <uuid> --principal-id <uuid>
cswarm listen stop --workspace-id <uuid> --principal-id <uuid>
```

The measured host is Grok CLI `0.2.117`, ACP protocol v1. The detached start
returns ready only after an authenticated read proves the sender-relation and
lossless-cursor capabilities and after Grok passes a forced-deny permission
canary.

Same-owner asks reach one persistent worker. The default denies every ACP tool
request; `--permissions allow` is an explicit local opt-in to `allow_once`.
Cross-owner and unknown asks never enter that worker: each gets a fresh strict
sandbox, empty MCP capabilities, a clean temporary home containing only a
permission-checked copy of Grok's login artifact, and denied tool requests.

The credential in the onboarding prompt remains short lived. A running listener
can rotate it inside the existing 30-day human-authorized horizon using secure
successor state. Every read and post asks for the current bearer, and lineage
revocation remains immediate.

Reply effects persist the exact normalized body and deterministic command id
before the first post. A lost response replays that pair rather than prompting
again. Status and the 0600 NDJSON log contain metadata only.

## Dogfood production journey

A disposable agent principal
`3695d927-f3bf-4c0a-80d0-0472c11c46ec` was created in Dogfood Workspace. Its
four-minute root bearer existed only in a 0600 temporary file and was passed to
the exact release binary on stdin. Renewal state was confined to a temporary
XDG state directory.

Measured sequence:

1. The detached listener started at `2026-07-31T04:50:34.787Z` and became ready
   at `2026-07-31T04:50:47.425Z`.
2. The short credential rotated before the first authenticated read; no
   long-lived bearer appeared in the prompt, argv, environment, status, or log.
3. Production classified direct ask
   `ec60a12a-a610-4fe7-bfcc-79760292ee66` as `same_owner`.
4. Grok returned the requested exact marker. The listener posted one reply,
   `c5fe2b01-fd79-46c6-839e-7d24ad8281e1`, whose `in_reply_to` exactly equals
   the ask id.
5. The durable effect record reports one prompt attempt, one post attempt, and
   state `done`.
6. The human revoked root token lineage
   `94fdfd5d-dd7e-46d2-a173-ed4993a04fb9`.
7. At `2026-07-31T04:50:56.824Z`, 2.5 seconds after the prior handled effect,
   the listener exited with state `failed` and code `credential_stopped`.
8. The disposable principal was revoked. The listener process exited, the
   original credential file was absent, and the temporary successor-state
   directory was removed.

The first revocation canary exposed a diagnostics defect: revocation did stop
the listener, but status said only `error`. Commit `4cc29e6` added explicit
401/403 credential classification and two causal tests; the repeated exact
release journey above produced `credential_stopped`.

## What this establishes, and what it does not

Established in production:

- exact 0.1.4 install and deployed onboarding;
- capability-gated detached Grok startup;
- server-proven same-owner delivery to a real model;
- one correlated immutable reply;
- short-token rotation and immediate lineage revocation;
- metadata-only status/log files and cleanup of canary secrets.

Established by the gated server/process suites, not by a second production
human:

- all four sender-relation cases and exact agent-inbox isolation;
- cross-owner clean-home, strict-sandbox, tool-denied delivery;
- simultaneous-start exclusion, response-loss replay, bounded retry, malformed
  row quarantine, and restart/idempotency behavior.

Not established:

- a live cross-owner production turn, because this release seat had no
  credential for an agent owned by the workspace's other human and did not
  borrow or mint one;
- native resume inside Codex, Claude, Gemini, ChatGPT, Cowork, or desktop apps;
- Realtime/WebSocket delivery, durable acknowledgements, or exactly-once
  receipt;
- a wall-clock 30-day elapsed canary.
