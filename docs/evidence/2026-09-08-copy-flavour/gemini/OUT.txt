## 2. Refutation Analysis

### (1) After `preventDefault()` plus `setData('text/plain', …)`, can ANY code path still put `text/html` on the clipboard from this block?
**Refutation Result: Refuted (No code path can put `text/html` on the clipboard).**
- Under the W3C Clipboard API and Events specification (Section 4), calling `event.preventDefault()` cancels the browser's default copy action (which serializes DOM selections to both `text/plain` and `text/html`).
- When the default action is canceled, the clipboard is populated *exclusively* with data formats explicitly registered via `event.clipboardData.setData()`.
- The handler in [AgentConnect.astro](file:///Users/yulanbot/Developer/Ridge.io/cloud-swarm/site/src/components/connect/AgentConnect.astro#L334-L339) invokes only `clipboard.setData("text/plain", ...)`. No code path calls `setData("text/html", ...)`.
- No other ancestor or bubble listeners attach to `copy` across the site codebase. Even if an ancestor listener were present, `event.preventDefault()` sets `defaultPrevented === true`, suppressing browser HTML synthesis.
- If `!clipboard` or `!this.#prompt`, the handler early-returns without modifying the event or calling `preventDefault()`. When a prompt is loaded in any standard browser, `clipboardData` is present, `text/plain` is set, and default handling is prevented.

### (2) `promptCopyPayload` returns its input byte for byte — no escaping, no trimming of the returned value — and the empty/whitespace fallback cannot swallow a legitimate one-character selection.
**Refutation Result: Refuted (Byte-for-byte fidelity holds; cannot swallow legitimate single characters).**
- In [agent-prompt.ts](file:///Users/yulanbot/Developer/Ridge.io/cloud-swarm/site/src/components/connect/agent-prompt.ts#L93-L95):
  ```typescript
  export function promptCopyPayload(selectionText: string, fullPrompt: string): string {
    return selectionText.trim().length > 0 ? selectionText : fullPrompt;
  ```

- When `selectionText.trim().length > 0`, the return expression returns `selectionText` directly without trimming, escaping, or character replacement.
- For any legitimate one-character selection (e.g. `{`, `"`, `_`, `$`, `c`, `1`, `\`, `/`), `ch.trim().length` evaluates to `1 > 0`, returning `ch` byte-for-byte.
- The only 1-character selections that evaluate to `trim().length === 0` are isolated whitespace glyphs (`" "`, `"\t"`, `"\n"`). Legitimate prompt payloads and commands do not consist of isolated whitespace, while keyboard copy without a selection or accidental zero-character clicks correctly fall back to `fullPrompt`.
