**2. Foster parenting.** On the render path, every `table` / `thead` / `tbody` / `tr` / `th` / `td` open tag is well-formed and in `ALLOWED_TAGS`; `sanitizeTag` always returns that open tag (with or without `align`). Header-only tables emit `<tbody></tbody>`, which the parser does not foster. The observer probe now reads previous-sibling text and has a positive `LEAKED` control.

**3. Cells are not a second escaping path.** `renderTableRow` / `renderListItem` call the same `renderInline`. Hostile vectors are byte-identical in a cell and in a paragraph. `\|` inserts a raw `|` into already-escaped text; `|` is not markup, and `<` is already `&lt;`. `\*` and `\_` in a cell stay literal. The code-span `\|` difference is the documented GFM exception, pinned in both directions.

Unescaped `|` inside a markdown URL in a *body* row splits the row (`| [l](https://example.com/a|b) | x |` → three cells, then autolink on `https://example.com/a`). Ugly, not a second escape path: the `<a>` is complete inside the first `<td>`.

**4. Task items are not checkboxes.** `TASK_ITEM` is `$`-anchored on `[ ]` / `[x]` / `[X]`.
