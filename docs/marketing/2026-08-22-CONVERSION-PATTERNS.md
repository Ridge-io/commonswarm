# Conversion patterns for the homepage (ShipFast/DataFast study, 2026-08-22)

Extracted as technique, not wording. Each pattern below carries its HONEST CommonSwarm
implementation; anything requiring fabricated proof is in the do-not-use list. Ranked by
expected impact on "a dev opens /app or runs the install command".

1. PAIN ARITHMETIC (high) — itemize the cost of uncoordinated agents the way devs estimate
   work: duplicated refactors, two agents in the same file, a human re-explaining state to
   every session. Pivot: one posted update, everyone unblocked. Structural claims only; no
   customers needed.
2. CODE AS HERO PROOF (high) — for a CLI the demo IS a code block: the real install line and
   a real posted signal, monospace, centerpiece placement.
3. PROOF ADJACENT TO EVERY CTA (high) — our honest inventory: public repo, open free tier
   (no card, no invite — true via SWARM_SELF_SERVE), version + release cadence, a real
   session transcript. "Open-source, self-serve, free" is our risk reversal.
4. OBJECTION FAQ WITH REAL ANSWERS (med-high) — including the "why not a shared Slack
   channel?" slot answered qualitatively, and "does a signal lock work?" answered no.
5. MAKER VOICE (med) — short first-person on why this was built: agents stepping on each
   other in a real fleet; this repo is the dogfood. No revenue/follower numbers.
6. SECTION RHYTHM (med) — alternating contrast bands, one idea per section, monospace for
   anything typed, bold outcome lines. Pure craft, no honesty cost.
7. THREE-STEP HOW-IT-WORKS (med) — install, join, post first signal.
8. ONE PLAYFUL TOUCH (low) — a single dry joke or easter egg, matching the calm voice.

DO NOT USE — dishonest for a free OSS tool with no customers:
- scarcity counters / "N left" pricing; strikethrough anchors (no price exists)
- revenue screenshots, dollar testimonials, inflated user counts or avatar walls
  (the D-023 class: falsifiable claims about deployment state)
- FOMO CTA framing; the honest and stronger frame is "start now, nothing to lose"

Caveat: single-pass text extraction; interactive behaviors inferred from markup.
