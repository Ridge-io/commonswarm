# SEO keyword research — alternatives/hub pages (DataForSEO, 2026-08-22, $0.33 spent)

Volumes are Google Ads monthly (US, en); KD is DataForSEO Labs 0-100. Raw JSON pool
(659 keywords) was in the session scratchpad; re-pull is ~$0.33 with the same calls.

## THE FINDING THAT GOVERNS EVERYTHING
Our homepage vocabulary is ZERO-VOLUME: "ai agent collaboration tool", "shared workspace
for ai agents", "slack alternative for ai agents", "coordinate multiple ai agents" all
return 0. The market's words are: ORCHESTRATION, SUBAGENTS, MULTI AGENT, A2A. The homepage
keeps the brand voice; the SEO pages must speak the search vocabulary.

## Page clusters, ranked (primary kw, volume, KD)
1. Claude Code subagents GUIDE — "claude code subagents" 2,900 KD19. SERP won by docs,
   Reddit, tutorials => build a practical guide ("running multiple Claude Code agents
   without collisions") that lands on cswarm as the coordination layer. Highest cell.
2. AI agent orchestration HUB — "ai agent orchestration" 590 KD8 (+ "agent orchestration"
   1,000 KD26, "multi agent orchestration" 720 KD16, framework/platform/tools variants
   KD6-10). SERP: IBM-style explainers + listicles => definitional hub + honest platform
   comparison distinguishing frameworks from a shared coordination workspace.
3. LangGraph ALTERNATIVES — "langgraph alternatives" 420 KD0; sibling "langgraph vs
   langchain" 1,900 KD0 (cheapest big keyword in the set). SERP: third-party listicles
   beat vendor pages => N-alternatives listicle with a vs-table, CommonSwarm placed
   honestly among real alternatives.
4. AI agent workspace PRODUCT HUB — "ai agent workspace" 1,000 KD34; secondaries "ai
   agent teams" 110 KD0, "best ai agent platform" 170 KD6, "multi agent ai platform" 320.
5. CrewAI ALTERNATIVES — "crewai alternatives" 180 KD0 + vs-family (crewai vs langgraph
   320 KD1). Same listicle shape as 3.
6. A2A protocol EXPLAINER — "a2a protocol" 3,600 KD37 + "agent to agent protocol" 1,000.
   Top-funnel; angle: protocol vs shared workspace.
7. AutoGen + OpenAI Swarm alternatives — small volumes but "openai swarm" 480 KD17 is
   deprecated => "what to use instead" writes itself.
8. Slack alternative (SECONDARY intent) — "slack alternative" 1,000 KD2, open-source/
   self-hosted variants KD0-3. Enterprise chat shoppers; cheap enough to try once.

## Do NOT build
- "Notion alternative for agents": "notion ai agents" (590) is about Notion's own AI.
- Discord/Linear + agent qualifiers: all <=10 volume.

## Format evidence (3 SERPs pulled)
Tool-comparison SERPs are won by third-party LISTICLES (zenml, ema.ai, safe.com), with
vendor vs-pages below them. Claude-subagents SERP is won by docs and tutorials. Match the
winning shape per cluster; product-page shape loses everywhere except brand terms.
